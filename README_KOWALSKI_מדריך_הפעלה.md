# מדריך הפעלה רשמי: קובלסקי (KOWALSKI) — ראש מטה ומזכיר אישי בכיר בוואטסאפ

ברוך הבא למערכת **קובלסקי (KOWALSKI)**, סוכן ה-AI האישי שלך מבית **GOR MARKETING**.

---

## 🚀 איך מפעילים את קובלסקי (חיבור ראשוני):

1. **התקנת חבילות (פעם אחת בלבד):**
   פתח טרמינל בתיקייה:
   `GOR_WORKSPACE/03_בוטים_ואוטומציות_AI/GOR_EXECUTIVE_WHATSAPP_ASSISTANT`
   והרם את הפקודה:
   `npm install`

2. **הפעלת הבוט:**
   הרם את הפקודה:
   `npm start`

3. **סריקת קוד QR בוואטסאפ (כמו WhatsApp Web):**
   - פתח את אפליקציית WhatsApp בטלפון שלך.
   - כנס ל-**הגדרות** -> **מכשירים מקושרים (Linked Devices)** -> **קשר מכשיר**.
   - סרוק את קוד ה-QR שמופיע בטרמינל.
   - **זהו! קובלסקי מחובר ופועל עבורך 24/7!**

## 🎯 פקודות ודוגמאות לשימוש יומיומי:

### 1. 🧠 למידה עצמית ורישום סקיל חדש:
- *"תלמד סקיל חדש: כשאיגור שואל על בדיקת דומיינים, תבדוק בגוגל מי הרשם ותחזיר מחיר ממוצע"*
- קובלסקי יוצר לעצמו קובץ בתיקיית `skills/` וזוכר אותו לתמיד.

### 2. 🔍 חיפוש וניתוח חי מ-Google:
- *"חפש בגוגל מסעדות שף מומלצות בהרצליה פיתוח ליום חמישי"*
- *"תבדוק מחיר ממוצע לכרטיס טיסה ללונדון בשבוע הבא"*

### 3. 📄 הפקת הצעת מחיר רשמית ב-Word (.docx) ישירות לוואטסאפ:
- *"קובלסקי, תייצר הצעת מחיר לכבוד חברת אופק נדל"ן עבור קידום ושיווק 360 במחיר 7,500 ש"ח"*
- קובלסקי יוצר מסמך Word מעוצב עם לוגו GOR ושולח לך אותו להורדה ישירות בצ'אט.

### 4. 🌅 תדריך בוקר וניהול משימות:
- *"מה הלוז שלי להיום?"*

- כל בוקר ב-08:30 קובלסקי שולח לך תדריך בוקר אוטומטי!

### 5. 🌍 תקשורת ב-5 שפות:
